🌐 View Website
💡 How it works: Use the sidebar to manage each content section. Click Add New to add an item, the ✏ Edit button to change it, or 🗑 Delete to remove it. Changes go live on your website instantly when visitors reload the page. No coding required!
Quick Actions
Sermon Library
📋 Tips: Add a YouTube URL so visitors can watch the sermon. Upload a thumbnail or paste an image URL. The first 6 sermons are shown on the homepage.
Photo Gallery
📋 Tips: Upload a photo or paste a URL. The first 6 photos appear on the homepage gallery. Categories: worship, events, outreach.
Member Testimonials
📋 Tips: Add real testimonies from church members. These appear in the sliding testimonials section on the homepage.
Upcoming Events
📋 Tips: The 3 nearest upcoming events appear on the homepage. Mark one as Featured to show a countdown timer. Past events are hidden automatically.
Kingdom Finance
📋 Tips: Edit the 4 giving categories shown on the homepage. Use an emoji as the icon. Click Save Changes when done.
📈 Visitor Analytics
Live Tracking — Visitors are tracked automatically on every page visit. Stats auto-reset at the start of each month. IP geolocation requires internet.
